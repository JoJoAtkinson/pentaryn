# Pentaryn Dice — how it was built (2026-11)

**Read this when:** you want to know why `pentaryn-dice` is shaped the way it is. Never load this to operate the module — the use-doc is `context/foundry/dice.md`.

## Goal

Feedback `Lzzlyq` (2026-11-19, for Kyle): "make multi-selecting dice easier". Joe clarified it is Dice So Nice's persistent dice: no select-all, the Ctrl+click hint hidden behind Help, and a click-drag selects tokens. Triage cluster M, unit M1 of the 2026-11-21 workflow (`context/plans/feedback-triage-2026-11-19.md` §M and §H2 M1).

## Decisions and rejected alternatives

| Decision | Alternatives rejected | Why |
|---|---|---|
| A new small-tier module over Dice So Nice, no DSN files touched | patching DSN; folding it into riders | no existing module owns DSN UI; riders is a rules module |
| Small tier + kit `settings` **and** `api` | small + settings only (the H2 command line) | `selftest()` and `status()` must be published with rows; the cursors module set the precedent (small + settings + api) |
| Spawn through `game.dice3d.persistent.spawn` | `box.spawnPersistentDie` | only `persistent.spawn` broadcasts and saves to the user's flags (H2) |
| Spawn one die at a time, a d100 as a link group | `Promise.all` | DSN places each die by the count already out; the sidebar's own `_spawn` does the same |
| Select by adding to `selectedPersistentDiceIds` + `onSelectionChanged()` | calling `togglePersistentSelection` per die | toggle would deselect already-selected dice; link groups are expanded in core `idsToSelect` instead |
| Selection is a union | replace the selection | "all D6, then all D8" is the natural way to build a mixed roll |
| Shortcut Alt+A, NORMAL precedence, returns false with none of your dice out | Ctrl+A with priority (H2's alternative) | Ctrl+A is core's select-all tokens; Shift+A is Argon's HUD toggle and A is core's moveLeft; Alt+A is free in core and every installed module (checked 2026-11-21) |
| `review_always: [dice-so-nice]` | `hold` | a hold would freeze DSN for good; recommended in H4 item 3 (Joe's pick was not recorded in the run, so the recommendation stands) |
| Count boxes capped at 30 | no cap | a typo (300) should not flood the table; DSN's maxDiceNumber is the real limit |

## Declared behaviour changes

- [declared] The Dice So Nice tab gains count boxes, "+ ×", select buttons and an inline hint (setting *Dice helpers in the Dice So Nice tab*, on by default).
- [declared] Alt+A selects all your persistent dice.
