**Bug still open (upstream, not fixed): a bridge restart race.** After a `kill -9` of the MCP backend, two wrappers each respawned one. The loser's wrapper exited even though it was already connected to the winner, and that dropped this session's `mcp__foundry__*` tools until a restart. The cause is in `packages/mcp-server/src/index.ts:172-178` of the fork: a wrapper whose spawned backend exits 0 while it is connected to a live broker should keep running. Changing it touches an upstream file, so it needs a FORK.md row. The hazard is documented in `context/foundry/README.md` (`84c11835`).

**Open for Joe** (features or decisions, not bugs; the full list is under "Open for Joe" below). The ones most worth a look:
1. **Wild Shape token art.** Shifting into an MM form with wildcard token art (wolf, cat) gives the mystery-man token and "Invalid Asset" errors. dnd5e copies the wildcard unresolved for players (it needs FILES_BROWSE), and core's `requestTokenImages` returns the literal wildcard. Transform could resolve the image itself, as riders already does for the summon preview. (TF-1, TF-2, D7-1)
2. **Name leak in study cards.** The closer-look stub and the GM share whisper use the actor name, not the token name the player sees. A GM-only world actor name could reach player chat. (TIE-3; the Item Piles loot window does the same, DB-1)
3. **A fresh PHB Wild Shape item is in `cr` mode**, which opens dnd5e's Compendium Browser instead of shifting at once. Either handle `cr` mode or document the setup Talo has (mode '' plus beast uuids). (TF-3)
4. **A hand-set token light is lost after a Wild Shape round trip**: the revert brings back the prototype light. Put standing lights on the prototype. (TF-2)
5. **The HUD allows Wild Shape, Change Form and Return in one turn** after the bonus action is spent. The pip greys out but nothing blocks the action. (TF-1)
6. **The aoe tray buttons overflow** their 24 px height in the normal-width chat sidebar. **Careful Spell stays armed for 10 minutes** out of combat, while aoe.md says "same turn". (AO-1)
7. **The PHB / classes24 Careful Spell has an empty activation type**, so Argon lists no Metamagic for a PC built from the PHB. Check Marrith. (RD-1)
8. **Doc mismatches to settle:** attunement `stash()` writes untrimmed slots, and the golden and README disagree about that (AT-3); the ties README says "GM also gets item marks", but players see them too (TIE-4); the combat README's Reaction row covers Reaction items only (CB-1); `pentaryn-combat.*` events are client-local and fire once per item used, not per swing (CB-2).

## Classification

One item per user-visible behaviour, each classified once by the test **"could a bridge assertion fail for the reason a player would complain?"** No → play.

- **bridge** — a deterministic API, data or state change driven and observed end to end with `pentaryn-read` / `pentaryn-write` / the MCP tools / eval-js (two ops items are read-only `make` reads of the same kind).
- **play** — the value is in the UI, HUD, dialogs, player-side visibility, multi-user or timing: one at a time in a `zz<n>.localhost` player tab plus the one GM tab.
- **not-testable** — needs a real player, other hardware, a forbidden action tonight, or Joe's judgement of feel: reason recorded, no attempt.

Totals: **82 items** — 35 bridge, 37 play, 10 not-testable; **27 big**.
