# Cursor icon sources

Unmodified originals. The module's cursors in `foundry/module/pentaryn-cursors/assets/cursors/` are
recoloured, outlined and rasterised
from these by `../build.mjs`; the shapes are the artists' work.

game-icons.net files come from <https://github.com/game-icons/icons> (`<artist>/<name>.svg`); each
carries a black `0 0 512 512` background rectangle as its first path, which the build strips.
Font Awesome Free files come from <https://github.com/FortAwesome/Font-Awesome> (`svgs/solid/`);
the licence comment is kept inside each file. Attribution for shipped builds: this file, copied
into the module's README.
