## Worth knowing

**Foundry MCP Bridge 0.8.4** ([release](https://github.com/adambdooley/foundry-vtt-mcp/releases/tag/v0.8.4)):
- **New: scene music.** You can bind playlists and tracks to scenes, create, edit and delete playlists, and control playback.
- **New: ActiveEffect management.** You can create, update and delete effects on actors and on their items.
- **New: `manage-actors` `place` action.** It drops an existing world actor onto the current scene. Before this, you had to create a new actor.
- **New:** a `replace-journal-page` tool.
- **Fixes:**
  - `use-item` targeting now works on V13/V14.
  - Large responses no longer time out over WebRTC.
  - Several D&D 5e feature-creation defects are fixed.
  - The module now uses `ws://` for loopback hosts even on HTTPS pages.
  - A journal page rename bug is fixed.

**Dice So Nice! 6.4.1:** the record has no release notes for it. See the [release page](https://gitlab.com/riccisi/foundryvtt-dice-so-nice/-/releases) if you want details.

## Held

**[dnd5e](https://github.com/foundryvtt/dnd5e/releases) 5.3.3 → 6.0.5 (major):** held on purpose.
- **Why:** 6.0 is the biggest system release so far. It reworks chat-card data and ActiveEffects (v2). Two installed add-ons may break: **enhancedcombathud-dnd5e** and **itempilesdnd5e**.
- **What you'd get:**
  - More compact chat cards, with targets grouped and a right-click menu per target.
  - Shift+click to apply several effects at once.
  - Conditional, rules-based and Region-attached ActiveEffects.
  - Automated falling and fall damage (uses the V14 Levels feature).
  - Better armor class handling.
- **The 6.0.x patches have fixed the worst early bugs:**
  - Some worlds failing to load (6.0.1).
  - An infinite loop when casting a concentration spell from a scroll (6.0.2).
  - Effects with no duration expiring after one turn in combat (6.0.3).
  - Immunity to exhaustion being ignored (6.0.4).
  - Errors on activity-requested checks and saves (6.0.5).
