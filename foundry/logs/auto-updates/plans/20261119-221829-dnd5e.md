## Steps

1. Back up the world. Confirm Foundry is on v14 (6.1 requires it) and that the 6.1 pre-release was never installed; if it was, uninstall it first.
2. Update dnd5e to 6.1.1 on a staging copy and let the world migration finish. Check the console for errors on ready.
3. Run make foundry-adjustments-check, then every per-module foundry check listed in FACTS.
4. Re-read dnd5e 6.1.1 config.mjs. Update the enums and TARGET_SYSTEM_VERSION "6.1" in build_actors.py, bump GENERATION, run pytest scripts/tests/.
5. Set the pentaryn-importer module.json targetSystemVersion to "6.1", run make foundry-sync, regenerate the payload and do one test import.
6. Check the 6.1 damage-application ignore/downgrade options. Adjust riders tray-preset.mjs and aoe packApplyOptions if needed, then re-run both checks.
7. Read 6.1.1 Tooltips5e#_positionItemTooltip. Retire the attunement tooltip guard if dnd5e now guards the missing element.
8. At the table: hover items during a re-render, apply Elemental Adept damage (GM and player), use Steady Aim and Rage, run one TWF/GWM Full Attack, cast a summon and an area.
9. Retire a row only after the table has confirmed the native behaviour.
10. Rollback rule: if the world fails to load or a check fails and cannot be fixed the same day, restore the backup and pin dnd5e 6.0.6.
