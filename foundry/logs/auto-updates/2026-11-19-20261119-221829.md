**Worth knowing about held updates:**
- **dnd5e 6.1.1** (held, see below) adds optional **Renown tracking with factions** (a new item type, shown on character and group sheets; enable under Variant Rules), an **Antimagic Region Behaviour** that suppresses magical effects and bonuses inside a region, and new rules for ignoring or downgrading damage resistances, immunities and vulnerabilities. The 6.1.1 patch fixes Vehicles ignoring AC calculations, enchantments not being suppressed by antimagic fields, creature Special Traits being editable in Play mode, and damage application failing to render when a target's base actor was deleted.
- **Foundry core 14.370** (held) includes security fixes for node.js, which Foundry says to take. It also adds players setting their own passwords and a Grid Space region tool.
- **foundry-mcp-bridge 0.8.6** (pinned) includes a security fix from 0.8.5: bridge queries are now accepted only from GM users. It also adds an in-character chat message tool and a dnd5e fix where removing a condition no longer deletes a larger effect such as Paralyzed.
