## Problems this run

- **Smoke test failed on all four worlds** (ardenford, ardenhaven, pentaryn, space-journey). The browser check could not run: no Chrome/Chromium on this host, so `game.ready` never became true. Set `CHROME_PATH` or install `google-chrome` or `chromium`. Until then the smoke test will keep failing regardless of what was updated.
- **Host Node rolled back to 24.21.0** because the worlds failed the smoke test on the new Node. The cause is probably the missing browser rather than Node itself, so the rollback may have been unnecessary.
- **Module recovery failed for both ddb-importer and theripper-premium-hub.** The backup list request was refused with a 400. On Foundry 14.369+, `/setup` rejects package actions while a world is active, and the same-origin guard also rejects a POST without a matching Origin header. Neither module was rolled back, so both are still on the new versions. To roll back manually, stop the active world, go to the setup screen, and restore the backups there, or use the snapshot restore above.
- **Neither update has been confirmed working in a running world.** Both are small patch bumps, so the risk is low, but a quick load of each world is worth doing.
