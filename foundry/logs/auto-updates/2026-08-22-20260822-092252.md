**No update run happened this week — and the original version of this report got the
reason wrong.** It is corrected below.

## What actually happened

consent dialog that nothing could display.

The `caffeinate -im` assertion is the receipt: PID 90627 held
`PreventUserIdleSystemSleep` continuously from 04:06:05, logging 15-minute summaries
all night, and died at 09:23:06 — the same second the run finished. **That process
was alive the whole time. It was stuck, not deferred.**

The Mac was plugged in and awake throughout. `PowerUIAgent` at 04:07:32 recorded
`externalConnected=1` at the 80% smart-charge cap; `lich` set `disablesleep=1` at
14:06 the previous day and logged no unplug until 09:23:30 today, *after* the run
finished; `pmset -g log` has zero Sleep/Wake/DarkWake events from 2026-08-21 13:50:55
onward. The watchdog did the same thing — launched 06:12:05, blocked on the same
dialog, reported at 09:22:52.

## What the original report said, and why it was wrong

It said the 09:22 start was "the signature of a run launchd deferred while the Mac was
asleep." That was not a finding; it was a hardcoded string. The gate compared
`datetime.now()` against the window and asserted a cause it had never measured —
nothing in that path looked at process start time, at `pmset`, or at whether launchd
had deferred anything at all. A run that started dead on schedule and then hung was
therefore guaranteed to be misreported as a sleeping Mac.

## Fixed

* The gate now reads `VTT_UPDATE_LAUNCHED_AT`, exported by
  `automation/bin/vtt-update.sh` as its first action, and distinguishes three cases:
  started outside the window (a genuine deferral), started inside it but checked late
  (**blocked** — reported as a fault with the measured delay), and no recorded launch
  time (says so rather than guessing).
* `vtt-update.sh` caps interpreter startup at 60s and the whole run at 90 minutes.
  macOS ships no `timeout(1)`, so it races the process against a sleeping killer. A
  five-hour silent hang becomes a 60-second logged failure naming the likely cause.
