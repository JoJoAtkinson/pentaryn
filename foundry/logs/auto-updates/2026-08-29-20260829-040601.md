## Worth knowing

Both releases are API/hook additions for macro and module authors — nothing changes in the UI, and no bug fixes were published.

- **[3.3.3](https://github.com/Aedif/multi-token-edit/releases/tag/3.3.3)** — `MassEdit.openPresetBrowser()` now takes an options object (`documentName`, `query`, `callback`, `closeOnPick`) and returns the app instance. Practical use: a macro can pop the preset browser pre-filtered to, say, tiles matching a search term, run a callback on whatever you click, and close itself — a one-click "drop this prop" macro instead of scrolling the browser by hand.
- **[3.3.2](https://github.com/Aedif/multi-token-edit/releases/tag/3.3.2)** — new `MassEdit.preImportFauxScene` hook; returning `false` cancels a FauxScene import. Only relevant if you're scripting scene imports.
