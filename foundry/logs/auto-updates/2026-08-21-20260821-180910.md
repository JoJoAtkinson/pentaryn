> `/setup launchWorld` refused (403) — a world is active, or admin auth was rejected.

This is very likely an *environment* problem, not a problem with 14.367 — package and world actions need Foundry sitting on the setup screen with no world active. **If a world was left running from your last session, that's the cause.** Return to setup before Saturday-night play ends, or after, and next week's run should go through.
