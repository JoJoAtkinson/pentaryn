# Templates

Content skeletons you **copy**, not guidance you read. For guidance, see
[`../CLAUDE.md`](../CLAUDE.md) and the file it routes you to.

| Template | For |
|---|---|
| [`faction-template.md`](faction-template.md) | A faction's `_overview.md` |
| [`location-template.md`](location-template.md) | A place under a faction's `locations/` |
| [`creature-template.md`](creature-template.md) | A creature or monster write-up |
| [`npc-combat-runner-template.md`](npc-combat-runner-template.md) | An NPC that needs Foundry stat mechanics — the markdown half; the action rows go in `foundry/actions.jsonl` via `combat_action_upsert` |
| [`item-template.md`](item-template.md) | A magic or notable item |
| [`quest-template.md`](quest-template.md) | A quest or adventure hook |
| [`party-template.md`](party-template.md) | A party's `_overview.md` |
| [`party-member-abilities-template.md`](party-member-abilities-template.md) | A party member's ability sheet |
| [`player-character-story-template.md`](player-character-story-template.md) | A PC's narrative/backstory file |
| [`session-planning-template.md`](session-planning-template.md) | Prep for an upcoming session |
| [`session-notes-template.md`](session-notes-template.md) | Recap after a session |

**Using one:** copy it to its destination (see
[`../context/world/README.md`](../context/world/README.md) for where things go), rename to
kebab-case, fill in the frontmatter — `created`, `last-modified`, `tags`, `status` — and
delete the instructional comments as you go.
